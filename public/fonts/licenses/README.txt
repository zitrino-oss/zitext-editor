Fonts bundled with ZITEXT Editor

The font files in public/fonts are the Latin subsets served by Google Fonts,
except Geist, which is the full Geist 1.200 release from Vercel's `geist`
package (version 1.3.1). They are bundled so the app needs no network access
to show them. They are not covered by ZITEXT's Apache License 2.0; each
family keeps its own license, and the full text of each is in this folder.
